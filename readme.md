# SpeedMine

A simple Meowtils extension for faster mining of obsidian and beds.

SpeedMine checks the first solid block behind your current target. It activates when the block behind the target is obsidian or a bed.

## Features

- Faster obsidian and bed mining
- Adjustable mining speed
- Adjustable block hit delay
- Optional debug box
- Green box for obsidian or beds
- Red box for other blocks

## Settings

- Speed: 0 to 100%
- Delay: 0 to 4
- Debug: Shows the block being checked

## NOTE

- SpeedMine is ported from [Open Myau](https://github.com/60124808866/OpenMyau) just added OBBY / BED check 

## Installation

1. Download or build the extension.
2. Add it to your Meowtils extensions folder.
3. Start Minecraft.
4. Enable SpeedMine.
